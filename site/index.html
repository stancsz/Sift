THE MECHANISM

A sieve, not a summary.

No model decides what to remember. Sift ranks older evidence against the current task, carries nearby diagnostic lines and follows bounded links between identifiers.

01 / INTAKE

History gets heavy

Tool output and routine chatter crowd out the one failure or decision that still matters.

02 / SIFT

Relevant evidence stays

Task-aware ranking preserves exact recent work and selects older excerpts that match the live request.

03 / CONTINUE

The agent keeps moving

A smaller working context leaves more room for the next tool cycle. If critical current work cannot fit, Sift refuses safely.

01 Extractive; no generated memory · 02 CPU-only; no added model dependency · 03 Fails closed when exact active work cannot fit

START SMALL · STAY LOCAL

Try it without
changing your stack.

Preview the standalone CLI from GitHub main with Python 3.11+ and Git—no manual clone or LiteLLM. Point an OpenAI client at 127.0.0.1:4011/v1, then use Ollama or any compatible base URL. Protected endpoints can use --api-key-env. Already use LiteLLM? Try the callback instead.

TERMINAL / LOCAL
# Ollama installed; run `ollama serve` first if needed
ollama pull qwen3.5:9b

# install the CLI preview from GitHub main (Python 3.11+ and Git)
# Windows PowerShell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install `
  "sift-context @ git+https://github.com/stancsz/sift.git@main"
.\.venv\Scripts\python.exe -m sift.cli serve `
  --base-url http://127.0.0.1:11434/v1 `
  --target 4096 `
  --tokenizer byte-estimate

# macOS / Linux
python3 -m venv .venv
.venv/bin/python -m pip install \
  "sift-context @ git+https://github.com/stancsz/sift.git@main"
.venv/bin/python -m sift.cli serve \
  --base-url http://127.0.0.1:11434/v1 \
  --target 4096 \
  --tokenizer byte-estimate

# in a second terminal, clone only to run the optional demo
git clone https://github.com/stancsz/sift.git
cd sift
python examples/ollama_compaction_demo.py --model qwen3.5:9b

Estimates aren’t model tokens. The standalone CLI’s byte-estimate budgets UTF-8 request size, not your model’s tokenizer; it cannot guarantee upstream context fit. The LiteLLM path can use its provider counter. Both paths leave critical recent work exact and refuse when it cannot fit.

GOOD FIT / HONEST LIMITS

For long-running agent work.

+ Reach for Sift when

  • Your agent has long coding or research sessions
  • Logs and tool output bury earlier evidence
  • You want deterministic selection without a second model
  • You can set a budget and measure task quality on your own workload

− Keep in mind

  • Compression can remove information; measured quality was lower in the published LongBench run
  • Token estimates vary by protocol and provider
  • It is not an agent memory database or a semantic summary
  • Verify task completion and quality before broad rollout
