## Available now

The tested GitHub `v0.10.0` pre-release is a Python library and LiteLLM Proxy callback. The unreleased `0.11.0.dev0` main branch adds a LiteLLM-free `sift serve` CLI for Ollama and OpenAI Chat Completions-compatible base URLs. Its explicit `byte-estimate` tokenizer measures UTF-8 request size; it is not a provider tokenizer and cannot guarantee upstream context fit. The site and README provide a deterministic no-inference demo with a local stub, which verifies request compaction and forwarding only.
