# Roadmap to adoption

Sift reduces repeated agent history with deterministic, extractive compaction. Its current limits matter: selected LongBench runs show a quality trade-off, and no held-out study yet proves reliable task completion, lower total cost, or faster work in real coding agents.

## Available now

The tested `v0.10.0` release is a Python library and LiteLLM Proxy callback. The unreleased `0.11.0.dev0` source also adds a LiteLLM-free `sift` command for OpenAI Chat Completions clients, including Ollama and other compatible base URLs. Its explicit `byte-estimate` mode measures UTF-8 request size; it is not a provider tokenizer and cannot guarantee context fit.

## Current adoption work

- **Reliable local checks:** the latest full local suite passed **375 tests on Python 3.14 in 103.42 seconds**, with 17 dependency warnings, after installing `.[litellm,test]` in a clean virtual environment. PR #7's [Python 3.12 Core smoke](https://github.com/stancsz/sift/actions/runs/39272382994) passed in 29 seconds. The four-version full matrix remains weekly/manual to keep ordinary PR CI short. An isolated Ubuntu/Python 3.12 suite previously passed all 370 tests with 17 warnings; the offline authored comparison returned 100/100 Sift hits and 0/100 head/tail hits.
- **Clear first use:** the README and site show a long-history deployment-setting retrieval example plus Ollama/other OpenAI-compatible base-URL setup without LiteLLM. The unreleased CLI installs directly from GitHub `main` without a manual checkout; a clean Windows virtual environment confirmed `sift serve` works with LiteLLM absent. The bundled demo still requires a checkout and verifies request compaction plus retrieval of its synthetic buried setting, not general answer quality. Desktop and mobile site sections received independent READY reviews. First-run comprehension is still unmeasured; inference-free user sessions await owner authorization.
- **Public site:** GitHub Pages is live at <https://stancsz.github.io/sift/>. PR #7 added an offline Full / With Sift interaction that uses a captured result from the real compactor; Pages deployed main commit `8ce6dd2` successfully, and the published URL returned HTTP 200. The GitHub repository homepage points to Pages.
- **Broader quality evidence:** the public LongBench v2 record covers the 100-question/three-repeat study, an incomplete one-repeat run with 446 matched rows from 503 exposed questions, and a four-task field-pruning pilot that remains behind Full context and off by default. These are development results, not a holdout. A prepared 344-pair/three-repeat cohort has a historical manifest reserve of $41.87, not a live quote or authorization; dispatch still requires prior-attempt/account reconciliation, a fresh route and price check, verified available funds, and a sufficient explicit user cap. AppWorld `test_challenge` remains parked: its stock runner writes task-keyed details, and its public data download is not split-scoped, so a test-free quarantine rehearsal has not been established. See the [evaluation record](docs/evaluation.md) and [source review and protocol](docs/evals/agent-holdout-source-review-2026-10-18.md).
- **Adoption evidence:** the Advisor council recommended three inference-free first-run sessions with developers who already use long-context workflows. The [session protocol](docs/evals/first-run-usability-protocol-2026-10-18.md) is independently reviewed and ready as a gated plan. No external participants have been contacted; sessions still need owner-authorized recruitment and a reviewed rendered preview. Record comprehension, setup time, blockers, relevance, and voluntary follow-through. Walkthrough completion is not adoption.
- **Compatibility:** automated checks cover non-streaming/SSE, incremental streaming, active tool-call/result turns, Bearer-key forwarding, upstream errors, and Ollama reasoning metadata. A local OpenAI Python SDK 2.54.0 → Sift → Ollama two-request tool round-trip passed on `qwen3.5:4b`, preserving `build-1842` while compacting both requests. This verifies that local loopback path, not other named clients or remote providers; check broader compatibility before a stable release.
- **Release:** `0.11.0.dev0` is installable from GitHub but is not a stable release or PyPI package. The standalone CLI smoke confirms the base install does not pull in LiteLLM; the base URL must still be an OpenAI Chat Completions-compatible endpoint, and `byte-estimate` cannot guarantee the provider's token count or context fit. A manual tag-based Trusted Publishing workflow and operator steps are prepared in [the release guide](docs/releasing.md); it verifies the selected stable tag, full suite, and offline comparison, builds and checks wheel/sdist, and smoke-tests both without LiteLLM before publishing. The public `sift-context` PyPI endpoint currently returns 404; owner-side pending-publisher configuration must be confirmed before first upload. Resolve the compatibility, evaluation, and adoption gates before a stable release.

## Evidence today

The [evaluation record](docs/evaluation.md) summarizes the completed 600-response LongBench v2 study, a broader but incomplete 503-question matched run, a four-task field-pruning pilot, and task-specific native-agent checks. All LongBench questions were exposed during development. The results are not blind validation, accepted-task quality, or proof of parity. Keep claims scoped to those datasets, denominators, and limitations.
